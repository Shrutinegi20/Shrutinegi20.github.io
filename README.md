# Shruti Negi — Data Analyst Portfolio

A responsive, dark-purple portfolio website inspired by the reference design you shared.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — layout, colours, responsive design and visual effects
- `script.js` — mobile navigation, theme toggle and current year

## Publish with GitHub Pages
1. Create a **public** repository named `Shrutinegi20.github.io` (use your GitHub username exactly).
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. After publishing, your website address will be: `https://shrutinegi20.github.io`

## Personalize before sharing
1. Replace `your.email@example.com` in `index.html` with your professional email.
2. Replace the LinkedIn placeholder with your actual LinkedIn profile URL.
3. Add a professional photo in `assets/` and replace the `.portrait-placeholder` block with an `<img>` element, or keep the initials placeholder.
4. Add your resume as `resume.pdf` in the repository root.
5. Replace sample project descriptions and placeholder links with real project repositories, screenshots and verified insights.
6. Remove skills you cannot confidently explain in an interview.

## Important
The second and third project cards, certificate area, contact email, LinkedIn link and resume link are placeholders. Update them before sending the website to recruiters.
